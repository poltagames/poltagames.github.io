      WORK

      What I Make

      I can take on games of any genre. Whether something is technically feasible, and the fee, we'll decide together as we talk it through.

      How I Use AI

      • Since 2026 I've moved to vibe coding (writing code in conversation with AI), and I use Claude Code as a tool in my programming.
      • I'll use generative AI for assets if requested, but I generally prefer to work with prepared assets.
      • I want to discuss carefully with each client how generative AI is handled.
      • In my own projects, I use generative AI only for things like simple modeling, simple textures and materials, building tools for making sound effects and textures, and translation, never for anything that significantly affects how a game looks.
